# 地域創生メンターMTG：全体ミーティングの改善提案（他メンター共有用）

- 使い方: 下の「共有文」をそのまま LINE / Slack に貼る

## 共有文

お疲れさまです。
先日のメンターMTGで出た改善方針について、私から具体案を2つ提案させてください。

■ 改善したいこと（MTGで出た方針）
1. ブレイクアウトルームの活用を続ける
2. 発言の少ない参加者を指名する
3. 内輪ノリをおさえ、「締める時間」を意識する
4. 「KPIが未達でも仕方ない」という空気を変える

■ 提案①：ワークを取り入れる
MTGの中に、自分で考える時間を2回つくります。
・冒頭5分：この1ヶ月の振り返り
・終盤5分：次の1ヶ月の目標
→ 自分ごととして考える時間をとることで当事者意識が高まり、「未達でも仕方ない」の空気を変えることにつながると考えています。（課題4）

■ 提案②：アジェンダを組みなおす
ブレイクアウトルームを「後半」に移します。
・その日の学びを、すぐにアウトプットできる
・集中が切れてくる時間に話し合いを入れることで、最後まで集中が続く
・前半30分で運用報告までテンポよく終えることで、「前半＝締まった時間／後半＝交流の時間」とメリハリがつく（課題1・3）

■ 進行イメージ（60分の場合の例）
0:00〜0:05　ワーク：1ヶ月の振り返り
0:05〜0:30　運用報告
0:30〜0:50　ブレイクアウトルーム
0:50〜0:55　ワーク：次の1ヶ月の目標
0:55〜1:00　締め（数名を指名して目標を発表）
※最後の発表で、発言の少ない方を優先して指名します（課題2）

ご意見いただけたらうれしいです。よろしくお願いします。

## 内輪ノリをおさえる追加案（代表の検討用・必要なものだけ共有に足す）
| 案 | 中身 | ねらい |
|---|---|---|
| A. 司会とタイムキーパーを毎回交代 | メンターが持ち回りで担当。時間が来たら「次に進みます」と区切る | 「締める」役目を仕組みにする |
| B. 運用報告の型を統一 | 1人2分で「数字 → うまくいかなかった理由 → 次の一手」 | 雑談に流れない。未達でも次の一手まで言う習慣がつく |
| C. 雑談の場所を分ける | 開始前5分と終了後を「自由に話せる時間」として残す | 交流は否定せず、本編と切り分ける |
| D. ブレイクアウトにお題と持ち帰りを決める | 各部屋で「明日から試すこと1つ」をまとめてチャットに投稿 | 部屋の中が内輪の雑談で終わらない |
| E. 冒頭でグラウンドルールを1行読む | 例：「全員がわかる言葉で話す」「時間を守る」 | 新しい人も入りやすい空気をつくる |

- おすすめ: **B と C**。B は課題3・4の両方に効き、C は今の良い雰囲気を壊さずにメリハリだけつけられる。
- 「60分」は仮の長さ。実際のMTGの長さに合わせて時間配分を直す。
