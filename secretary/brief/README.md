## 毎日のタスク（2026-09-25 更新）
- 循環器 15フォロー・20リプ：**15分×6枠**（2026-09-28 変更。1枠＝3フォロー・4リプ目安）

  - 平日（火〜金）: 朝7:00自宅／行きの電車1枠／帰りの電車1枠／帰宅後2枠（間に別作業）／夜22:30自宅
  - 月曜: 朝7:00／昼12:00（出勤前）／行きの電車1枠／帰りの電車1枠／夜2枠
  - 休日: 7:00／12:00／18:00／22:30＋2枠
  - 慣れて速くなったら4枠に減らす（参考にした優秀な運用者の型は1日4枠×15分）
  - 🔴 **KPIは業務委託の仕事。絶対に減らさない**（代表の指示 2026-09-29）。寝坊・予定変更で枠が消えたら、急ぎでない予定（決裁・調べもの・先の締切の作業）を後日に回して6枠を確保する
  - 🔴 **KPIを2枠（30分）続けて入れない**。枠と枠の間に簡単な別作業を挟む（Facebookコメント、連絡返信、スプシ記入、カタログを読む、5分休憩など）
    - 例（通勤60分）: KPI 15分 → FB 10分 → KPI 15分 → 休憩・連絡 5分 → KPI 15分

- 予祝＋**振り返り**：寝る前20分。「日報を書く」ではなく「今日のフォロー数・行動数を振り返り、日報スプシに記入する時間」として出す（代表の指示 2026-09-25）

## 起床時刻（`wake`）
- 初期値は「最初の予定（出発）の75分前」（朝の準備＋7:00のKPI①）。平日 7:45 出発 → 6:30。前夜が遅い日は、朝のKPIコマを帰りに回して起床を遅らせる案も検討する
- 代表から起床ルールの指定があればそれに従う

## 表示の優先順位（上から）
1. **今日中に必ず**：その日締切の提出物 → 毎日のタスク（循環器 15フォロー・20リプ／予祝／日報）→ 前日やり残したこと
   - 前日に未完了だったものは「昨日の分も」と明記して最上段へ
   - 予祝＋振り返り（スプシ記入）は「寝る前20分」。移動中にスマホを触れる時間があればそこに入れてもよい
2. **タイムスケジュール**：Google カレンダーの予定 ＋ 勤務・通勤（`secretary/schedule/base-week.md`）＋ 各タスクを入れる時間
3. **近い締切**：3件まで。「あと◯日」と、そのために今日・明日やる準備
4. **隙間時間があれば（決裁）**：`decisions/pending/` の件数・期限・所要分数のみ。急かす言葉は使わない
5. **明日**：1行
