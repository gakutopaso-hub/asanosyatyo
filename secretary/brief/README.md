# 段取り表（秘書の手順・毎晩22:00に翌日分）

公開先: https://claude.ai/artifact/A1HnFEX9qSeySJhQqoJT6a （`secretary/brief/index.html` を同じパスで再公開すると同じ URL が更新される）
更新: **毎晩 22:00 JST に「翌日分」を作る**（Routine）＋ 代表の予定が変わったとき
- 翌日の予定で起床時刻が変わるため、朝ではなく前夜に出す（代表の指示 2026-09-25）

## 代表の指示（2026-09-24）
- **iPhone 13 の画面（390×664 程度）でスクロールなしで見られること。**
- **その日にやるべきこと・その日の締切を最優先で見せる。** 今日のことが終わっていないのに、先の締切の決裁を次々迫らない。
- 決裁は代表が隙間時間にやる。段取り表では最下段に小さく、件数と期限だけ。

## 毎日のタスク（2026-09-25 更新）
- 循環器 15フォロー・20リプ：**30分×3コマ**（30分で8フォローが上限）。平日は行きの電車2コマ＋帰りの電車1コマが基本
- Facebookコメント：約10分
- 予祝＋**振り返り**：寝る前20分。「日報を書く」ではなく「今日のフォロー数・行動数を振り返り、日報スプシに記入する時間」として出す（代表の指示 2026-09-25）
- 当日の途中経過が届いたら（例「2フォロー10リプ済」）、残り数を段取り表に反映して再公開する

## 起床時刻（`wake`）
- 初期値は「最初の予定（出発）の60分前」。平日 7:45 出発 → 6:45。前夜が遅い日は、朝のKPIコマを帰りに回して起床を遅らせる案も検討する
- 代表から起床ルールの指定があればそれに従う

## 表示の優先順位（上から）
1. **今日中に必ず**：その日締切の提出物 → 毎日のタスク（循環器 15フォロー・20リプ／予祝／日報）→ 前日やり残したこと
   - 前日に未完了だったものは「昨日の分も」と明記して最上段へ
   - 予祝＋振り返り（スプシ記入）は「寝る前20分」。移動中にスマホを触れる時間があればそこに入れてもよい
2. **タイムスケジュール**：Google カレンダーの予定 ＋ 勤務・通勤（`secretary/schedule/base-week.md`）＋ 各タスクを入れる時間
3. **近い締切**：3件まで。「あと◯日」と、そのために今日・明日やる準備
4. **隙間時間があれば（決裁）**：`decisions/pending/` の件数・期限・所要分数のみ。急かす言葉は使わない
5. **明日**：1行

## 作り方
- `index.html` の `<script id="brief" type="application/json">` の中身だけを書き換える（デザインは触らない）。
- `lead` はその日いちばん大事な一言（例:「今日は週次報告の締切。12時までに提出」）。
- `must` の各項目は 3〜4 件まで。`timeline` は 5 行まで。長い文は切る。
- 書き換えたら 390×664 で縦に収まるか確認 → 同じパスで Artifact を再公開 → git commit & push。
