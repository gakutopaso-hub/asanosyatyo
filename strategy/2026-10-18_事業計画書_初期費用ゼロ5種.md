## 計画1：医療系SNS運用代行

| 項目 | 内容 |
|---|---|
| 概要 | クリニック・薬局・医師個人のX（旧Twitter）運用を代行する。投稿作成・交流・月次報告まで |
| お客さん | 開業医、クリニックの院長、調剤薬局、医療系の発信をしたい医師 |
| 強み | 循環器内科アカウントの運用実績【事実】、薬剤師として医療情報の正確さを担保できる |
| 価格【仮定】 | 月5万円（投稿20本＋交流＋月次報告）。既存の堀さん案件は次の更新で見直しを相談 |
| 初期費用0の理由 | 必要なのはスマホとPCだけ。実績は今の案件で作れる |
| 最初の30日 | ①今の案件の成果（フォロワー推移・反応の良い投稿）を1枚の実績資料にまとめる ②知り合いの医師・薬局に3件声をかける ③投稿作成の手順書を作り、編集担当（AI）が下書きできる状態にする |
| 90日の目標 | 新規1件の契約。1件あたりの作業時間を月8h→4hに減らす |
| 見る数字 | 契約件数、1件あたりの作業時間、お客さんのフォロワー増加数 |
| リスク | 時間を食う（今の時給は約270円【事実：10/11試算】）。外注・AI化ができないと件数を増やせない |

## 計画2：医療広告・薬機法の表現チェック

| 項目 | 内容 |
|---|---|
| 概要 | 医療・健康系の投稿や広告文を、公開前に薬剤師の目でチェックし、言い換え案を付けて返す |
| お客さん | 医療系の運用代行会社、健康系インフルエンサー、クリニックのWeb担当、サプリ・健康商品の販売者 |
| 強み | 「薬剤師」×「SNS運用の実務」の両方を持つ人は少ない |
| 価格【仮定】 | 月3万円（月20本まで）／単発1本1,500円 |
| 初期費用0の理由 | 必要なのは知識と、チェック結果を返す型（テンプレート）だけ |
| 最初の30日 | ①チェック項目表（NG表現→言い換え例）を作る ②自分のXで「この表現、実はNG」という投稿を週1本出して見込み客を集める ③運用代行会社2社に無料で3本チェックを試してもらう |
| 90日の目標 | 月額契約1社 |
| 見る数字 | 問い合わせ数、無料お試しから契約になった割合 |
| リスク | 法律の最終判断はできない（弁護士の領域）。「薬剤師としての表現アドバイス」と範囲を明記する |

## 計画3：SNS運用メンター＋少人数講座

| 項目 | 内容 |
|---|---|
| 概要 | 今のメンター業務（月1万円【事実】）を、個別プランと少人数のオンライン講座に広げる |
| お客さん | 本業を続けながら発信を始めたい人、SNS運用を仕事にしたい人。志スクール生とも相性が良い |
| 強み | メンター実績と、「本業＋副業」を回している自分自身の体験 |
| 価格【仮定】 | 個別：月3万円（月2回の面談＋レポート添削）／講座：月1万円（月2回のグループ会） |
| 初期費用0の理由 | オンライン面談ツールは無料のもので足りる。添削はメンター担当（AI）が下書きする |
| 最初の30日 | ①今のメンティーの成果をまとめ、紹介文に使ってよいか許可をもらう ②個別プランの内容と申込文を作る ③志スクール内・Xで募集する |
| 90日の目標 | 個別2人、講座の初回3人 |
| 見る数字 | 申込数、継続率（3か月続く人の割合） |
| リスク | 教える時間が増えすぎる。講座は録画を残して、同じ内容を何度も話さない仕組みにする |

## 計画4：個人事業主向け「AI秘書」導入サポート

| 項目 | 内容 |
|---|---|
| 概要 | 岳燈で作った仕組み（毎晩の段取り表・待受画像・カレンダー確認・決裁書）を、忙しい個人事業主に設定してあげる |
| お客さん | 志スクール生、経営スクールの仲間、ひとり社長、副業をしている会社員 |
| 強み | **自分が毎日使っている実例そのものが商品見本になる** |
| 価格【仮定】 | 導入（設定と使い方レクチャー）8万円＋月額サポート1.5万円 |
| 初期費用0の理由 | 自分の仕組みをテンプレート化するだけ。AIの利用料はお客さん側の契約 |
| 最初の30日 | ①自分の1日（待受画像・段取り表）をスクールで見せて反応を見る ②興味を持った2人に無料で試してもらう ③設定手順書を作る |
| 90日の目標 | 有料導入2件 |
| 見る数字 | 導入件数、月額の継続率 |
| リスク | お客さんの情報（カレンダー等）を扱うので、権限の範囲と情報の扱いを契約で明記する |

## 計画5：「心臓と血圧・薬の飲み方」健康セミナー講師

| 項目 | 内容 |
|---|---|
| 概要 | 循環器の知識と薬剤師の立場から、高血圧・心臓病の予防や薬の正しい飲み方を、企業・地域で話す |
| お客さん | 健康経営に取り組む中小企業、公民館・自治会、高齢者向け施設、薬局のイベント |
| 強み | 循環器アカウントで作った分かりやすい図解や投稿を、そのまま資料にできる |
| 価格【仮定】 | 1回60分 4万円（企業）／地域向けは1〜2万円 |
| 初期費用0の理由 | 資料はスライドで作れる。会場はお客さん側 |
| 最初の30日 | ①60分の資料を1本作る（投稿を再利用） ②知り合いの経営者（経営スクール・志スクール）に「社内で話せます」と声をかける |
| 90日の目標 | 1回目の開催（無料でも可）→ 写真と感想を実績にする |
| 見る数字 | 開催回数、1回あたりの単価、紹介で次につながった数 |
| リスク | 個別の病状への助言はしない（一般的な情報提供に限る）。勤務先との関係で名前を出せるか確認する |
