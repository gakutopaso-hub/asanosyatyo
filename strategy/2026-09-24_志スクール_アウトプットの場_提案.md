## 1. ねらい
学んだことを「出す」ことで、学びが定着し、仲間とつながり、成長が目に見える場をつくります。
設計の軸は **「楽しいから続く」** です。忙しい社会人でも負担にならず、運営の手作業がほとんど要らない仕組みを目指します。

### 楽しさの5原則
| 原則 | 具体策 |
|---|---|
| ① 1分で出せる | 決まった3行の型（学んだ／やった／次やる）。長文・完成度は求めない |
| ② 必ず反応が返る | 投稿したら直前の人に一言返す「バトン方式」。反応ゼロの投稿が生まれない |
| ③ 成長が見える | 自分の投稿がシーズンごとに1枚にまとまる（後述「志の名刺」） |
| ④ ゲーム性 | 4週1シーズン制、テーマ週、連続記録、称号 |
| ⑤ 義務・晒し上げにしない | 順位表は出さない。表彰は「達成した人」だけを名前で紹介。未投稿の人は一切言及しない。「おやすみ券」あり |

## 2. 前提（現時点の仮定です。MTGで確認させてください）
- 地域をまたぐ（関東・関西など）オンライン中心のコミュニティで、Slack・Discord・LINE・Facebookグループなど何らかのチャットツールを既に使っている。
- メンバーの多くは本業をもつ社会人で、平日にまとまった時間は取りにくい。
- 専任の運営スタッフはおらず、有志数名で回す。

## 3. 3つの案

| | A. 軽い「今日の1行」 | **B. 標準「志アウトプット・リーグ」（推奨）** | C. 挑戦的「チーム対抗・月例発表会」 |
|---|---|---|---|
| 内容 | 常設チャンネルに毎日好きなときに1行投稿 | 週1回・3行の型で投稿。4週1シーズン、毎週お題あり、バトン方式で反応 | 4〜5人のチームで毎月テーマに取り組み、月末にオンラインで5分発表 |
| 参加者の負担 | 1分／日 | **3〜5分／週** | 週30分＋発表準備 |
| 運営の負担 | ほぼゼロ | 週15分（AIでまとめ・集計） | 月2〜3時間（チーム編成・司会） |
| 楽しさ | 気軽だが、流れて埋もれやすい | 反応・称号・成長の可視化がそろう | 一体感と達成感が最も大きい |
| リスク | 数週間で投稿が途絶えやすい | 最初の1シーズンの火付けが必要 | 忙しい人が脱落し、置いていかれ感が出る |

**推奨は B です。** A の気軽さと C の達成感の中間で、「続く」と「楽しい」を両立できます。B が定着した後、希望者向けに C を「上級リーグ」として追加する段階的な進め方をおすすめします。

## 4. 推奨案 B の具体像

### 投稿の型（コピーして埋めるだけ）
```
#志リーグ W2
学んだ：〇〇
やった：〇〇
次やる：〇〇
バトン→（直前の人への一言）
```

### ゲームの仕組み
- **シーズン制**：4週で1シーズン。終わるたびにリセットされるので、途中参加・再挑戦がしやすい。
- **テーマ週**：毎週月曜にお題を1つ提示（AIが候補を出し、運営は選ぶだけ）。お題に沿わなくても投稿OK。
- **連続記録**：週1回投稿で「連続◯週」。各シーズンに1回「おやすみ券」（出さなくても記録が途切れない）。
- **称号（シーズン末）**：「皆勤（4週達成）」「ナイスバトン賞（コメントが一番喜ばれた人）」「行動賞（"次やる"を翌週"やった"にした人）」。書いた量ではなく、行動と仲間への貢献をたたえます。

### 最初の4週間（シーズン1：10/12〜11/8 の場合）
| 時期 | テーマ | 運営がやること |
|---|---|---|
| 準備 10/1〜10/11 | ― | 学長の了承、専用チャンネル作成、告知文の投稿（AIで作成）、MTG参加の4名が「火付け役」を担当 |
| W1 10/12〜 | 「私の今の志」自己紹介 | 火付け役4名が月曜朝に先に投稿し、空気をつくる |
| W2 10/19〜 | 最近の学びを1つ | 日曜夜に週間ダイジェスト（AI）を投稿 |
| W3 10/26〜 | 「やってみた」行動報告 | 途中経過を一言共有（「今週◯人がバトンをつなぎました」） |
| W4 11/2〜 | 仲間に届けたい一冊・一言 | シーズン表彰と「志の名刺」配布、1問アンケート |
| 振り返り 11/9〜 | ― | 指標の確認、シーズン2の改善点を学長に報告 |

### 必要なツール・役割
- **ツール**：既存のチャットツールに専用チャンネルを1つ。集計は投稿を週1回まとめてAI（ChatGPT・Claude等）に渡すだけで、ダイジェスト・連続記録・称号候補まで出せます。新しいツールの導入は不要です。投稿をAIでまとめることは開始時に告知し、AIに入れたくない内容は書かなくてよいことも明記します。
- **役割**
  - リーグ運営（1〜2名、週15分）：お題の投稿、週間ダイジェストの投稿
  - 火付け役（MTG参加の4名、最初の2週だけ）：先に投稿し、バトンを回す
  - 学長：シーズン末の表彰コメント（任意、月5分）

### 成功の指標（シーズン1で確認）
| 指標 | 目安 |
|---|---|
| 1回以上投稿した人 | アクティブメンバーの30%以上 |
| 4週継続率（W1投稿者のうちW4も投稿した人） | 50%以上 |
| 反応ゼロの投稿 | 0件 |
| 「楽しかった」（5段階アンケート） | 平均4以上 |
| 運営の作業時間 | 週30分以内 |

目安は仮の数字です。人数が分かり次第、調整します。

## 5. さらに一歩：アウトプットが「仕事と紹介」につながる導線
アウトプットを「出して終わり」にせず、**メンバーの実績と紹介の種**に変えます。

1. **「志の名刺」**：シーズンごとに、その人の投稿をAIが1枚のプロフィール（得意分野・取り組んだこと・次の挑戦）にまとめて本人に渡します。本人の作業はゼロ。成長の記録になり、メンバー同士の「この件なら〇〇さん」という紹介に使えます。
2. **「志の殿堂」**：各シーズンで特に良かったアウトプットを、**本人の同意を得たうえで**、学長の発信やコミュニティの公式発信で紹介します。メンバーには外部での実績と露出が、コミュニティには「ここに入ると行動する人になれる」という何よりの広告が生まれます。

関西の飲み会のようなオフラインの場で「名刺」を話題にすれば、オンラインとオフラインの交流もつながります。

## 6. MTGで確認したいこと（3点）
1. **規模とツール**：在籍人数・日常的に活動している人数と、使っているチャットツールは何か。
2. **学長が最も重視する目的**：学びの定着、メンバーの交流、外部への発信・集客のうち、どれを一番に置くか（称号や「殿堂」の設計が変わります）。
3. **運営と公開の範囲**：リーグ運営を引き受けられる方がいるか。優れたアウトプットをコミュニティの外に紹介してよいか。
