## 0. 結論（先に要点）

1. **ゴールは「個人事業の年間売上1000万円（月83万円）」を2年後（2028年9月）に置き、1年後（2027年9月）に「月45万円＝給与と合わせて年収1000万円」を中間ゴールにする。**
2. 今の時給は推定1,100円前後で、薬剤師の時給（推定約2,000円）より低い。**まず件数を増やすより単価を直すのが先。**
3. 本業を続けながら使える時間は月に約45時間が上限（推定）。月83万円をこの時間で出すには1時間あたり約1.8万円が必要なので、**「1対1の受託」だけでは届かない。2年目に「講座・顧問」のような1対多の商品へ移る必要がある。**
4. 月45万円までは本業フルタイムのままで届く計算。月83万円に進むときに「勤務日数を減らすか／外注を入れるか」を改めて決裁にかける（今は決めない）。
5. 医療ジャンルでは信頼が一番の資産。実績は実数だけを出し、クライアントの許可を得てから使う。「医師監修」と誤解させる表記はしない。

## 1. 「1000万」の定義比較

| | 案A：事業売上 年1000万 | 案B：給与＋事業で年収1000万 |
|---|---|---|
| 事業で必要な額 | 月約83万（年1000万） | 月45万（年540万） |
| 今との差 | 約28倍 | 15倍 |
| 本業との両立 | 1年目は可能。2年目に勤務調整か外注が必要になる可能性が高い | 本業フルタイムのままで届く計算 |
| 到達目安 | 2年（2028/9） | 1年（2027/9） |
| 注意点 | 課税売上が1000万円を超えた年の2年後から消費税の課税事業者になる【事実：消費税の免税点制度】。インボイス登録の判断も必要 | 「売上」と「給与」を足しているため、手取りの比較にはならない（事業は経費控除前） |

**推奨**：案Aを最終目標にし、案Bのラインを1年後の中間ゴールにする。どちらの道でも最初の1年でやることは同じなので、先に定義を決めても無駄になる作業はない。

## 2. 前提：時間と単価

### 使える時間【推定】
| 枠 | 時間/週 | 備考 |
|---|---|---|
| 月曜午前 | 約4h | 平日で一番大きい枠 |
| 火・水 夜 | 約6h | 休息を差し引き、実働 3h×2 |
| 木・金 夜 | 約1h | 疲れているので軽作業だけ |
| 土日のうち1日 | 約3h | もう1日は休息日として確保 |
| 通勤（往復2h×5日） | 軽作業のみ | 既存の運用（15フォロー・20リプ）でほぼ埋まっている |
| **合計（通勤を除く）** | **約14h/週 ≒ 月55h** | 余裕を残し、**計画上の上限は月45h** |

### 現在の時給【推定】
- 運用受託：毎日の運用30分×30日＋週次報告・投稿・月次報告 ≒ 月24h → 2万円 ÷ 24h ≒ **830円/h**
- メンター：月3h程度 → 1万円 ÷ 3h ≒ **3,300円/h**
- 合計：3万円 ÷ 27h ≒ **約1,100円/h**（薬剤師の時給は年460万 ÷ 年約2,200h ≒ **約2,000円/h**）

### 単価の仮定【仮定：リサーチ担当が10月中に相場を調べて置き換える】
| 商品 | 現在 | 仮定単価 | 単価の根拠となる強み |
|---|---|---|---|
| 医療系X運用代行（クリニック・医療者向け） | 2万/月 | 5〜8万/月 | 薬剤師による表現チェック（薬機法・医療広告ガイドライン）込み |
| 1対1メンター | 1万/月 | 2〜3.5万/月 | 添削に加えて、翌月すぐ使える施策と投稿の型を渡す |
| 医療投稿の表現チェック（単発） | なし | 0.5〜1万/本 | 薬剤師として根拠と表現を確認する。ただし「医師監修」とは名乗らない |
| 講座「医療者のためのX発信」 | なし | 5〜6万/人 | 録画教材＋月1回のライブ。AI社員が作った型をそのまま渡す |
| 医療機関向けの運用顧問 | なし | 10万/月 | 院内スタッフが運用し、代表は月1回の助言と表現チェックを行う |

## 3. フェーズ別ロードマップ

### Phase 0：土台づくり（〜2026/10末）
- **月売上目標**：3万（現状維持）
- **代表がやること**（合計2h程度）：①勤務先の就業規則で副業の可否・届出を確認する ②既存クライアントに、実績を匿名化して紹介してよいか聞く ③本決裁に回答する
- **AI社員がやること**：リサーチ担当＝医療系運用代行・メンター・講座の相場調査／戦略責任者＝料金表と商品設計／企画担当＝代表自身の発信の場の設計（進行中の「アウトプットする場」タスクと合流させる）／秘書＝開業届・確定申告の準備タスク化
- **次に進む条件**：副業に問題がない／料金表が決裁済み

### Phase 1：単価を直す（〜2026/12末・3ヶ月）
- **月売上目標：10万**
| 商品 | 単価×件数 | 月額 |
|---|---|---|
| 既存の運用受託 | 2万×1（次回更新時に付加価値つきで値上げを打診） | 2万 |
| 新規 医療系運用代行 | 5万×1 | 5万 |
| メンター（既存） | 1万×1 | 1万 |
| メンター（新規） | 2万×1 | 2万 |
- **必要時間**：約25h/月（運用1件あたり8hまで短縮することが前提）
- **代表**：新規の商談1〜2回（オンライン、月曜午前）、投稿の承認だけ
- **AI社員**：運用業務のテンプレ化（週次・月次報告の下書きを自動で作る）、提案書・料金表の作成、代表自身の発信のネタ出し
- **次に進む条件**：新規の有料顧客が2件以上／運用1件あたりの作業時間が8h以下

### Phase 2：件数を増やす（〜2027/3末・6ヶ月）
- **月売上目標：25万**
| 商品 | 単価×件数 | 月額 |
|---|---|---|
| 医療系運用代行 | 既存4万（更新後）＋5万×2 | 14万 |
| メンター | 2万×4 | 8万 |
| 表現チェック（単発） | 1万×3本 | 3万 |
- **必要時間**：約36h/月（運用7h×3＋メンター3h×4＋チェック3h）→ **上限の月45hに近づく**
- **代表**：月1回の商談、添削の最終確認、表現チェックの最終判断（薬剤師としての責任部分）
- **AI社員**：受講者・顧客から出た質問をまとめて講座の教材の素案にする。お客様の声（許可を得たもの）を集めて整理する
- **次に進む条件**：時間が上限の8割を超えた／同じ質問が何度も来る（＝講座にできる）状態が確認できた

### Phase 3：1対多へ移る＝中間ゴール（〜2027/9末・1年）
- **月売上目標：45万（案Bのゴールライン）**
| 商品 | 単価×件数 | 月額 |
|---|---|---|
| 講座「医療者のためのX発信」 | 5万×4人/月 | 20万 |
| 医療系運用代行 | 6万×3（単価の低い案件は入れ替え） | 18万 |
| メンター（講座修了者の上位コース） | 3.5万×2 | 7万 |
- **必要時間**：約35h/月（講座のライブと販売で8h、講座制作はPhase 2の間に分割して終わらせる）
- **代表**：講座の月1回ライブ（土日のどちらか）、表現の最終チェック
- **AI社員**：講座教材・受講者サポートの一次対応の下書き・募集の投稿案を作る
- **次に進む条件**：講座の成約が3ヶ月続けて月3人以上／受講者の満足度（アンケート）が8割以上
- **判断ポイント**：案Bを選んでいればここで達成。案Aを選んでいれば、Phase 4の進め方（勤務調整／外注）を決裁にかける

### Phase 4：事業1000万（〜2028/9末・2年）
- **月売上目標：83万**
| 商品 | 単価×件数 | 月額 |
|---|---|---|
| 講座 | 6万×8人/月 | 48万 |
| 医療機関向けの運用顧問 | 10万×2 | 20万 |
| 医療系運用代行（高単価の案件だけ残す） | 8万×2 | 16万 |
- **必要時間**：約55〜60h/月 → **月45hの上限を超える**
- **選べる道**（1年後に決裁する）：①勤務を週4日にする（給与は約2割減る見込み【仮定】）②運用代行の実作業を人に外注する（外注費で利益率が下がる）③講座の比率をさらに上げて時間を圧縮する
- **無理な前提は置かない**：Phase 3の実績が条件を満たさなければPhase 4には進まず、案Bの水準で安定させる

## 5. 信頼を守るルール（すべてのフェーズ共通）

- 実績は実数だけを出す。「フォロワー◯倍」のような数字は、期間と条件を併記し、クライアントの許可を得たものだけ使う。
- 「稼げる」「誰でも」「必ず」といった表現で講座を売らない。
- 薬剤師として確認できる範囲（薬の情報、表現の適否）を超えて、診断・治療を監修しているように見せない。
- 医療情報の根拠確認を最優先する。売上のために投稿の品質を落とさない。
