## 0. 結論（先に要点）

1. **Threadsは「志スクールの宣伝アカウント」にはしない。「本業を持ちながら志を形にしている人の記録」として発信し、共感した人とだけ個別に話す。** 紹介は、相談の中で相性を確かめてから行う。
2. **導線**：Threadsの投稿 → プロフィール・固定投稿 → DMで「話を聞きたい」→ 20分の相性確認（代表）→ 志スクール公式の説明会・体験 → 入学。**詳しい説明は志スクール側に任せ、代表の時間を相談1件20分に抑える。**
3. **最初の2週間は志スクールの名前を出さない。** 紹介ルールと報酬の表示方法を確認するまでは、自己紹介と価値提供の投稿だけで土台を作る。
4. **報酬関係は必ず明示する**（プロフィール・該当する投稿・相談の冒頭の3か所）。ステマ規制の対象は主に広告主（志スクール）だが、紹介者としての信頼を守るため、規制の範囲に関係なく明示する。
5. **薬剤師の本業・医療情報とは完全に切り分ける。** 健康や薬の質問には答えず、かかりつけ医・薬剤師への相談をすすめる。循環器の受託アカウントとは一切つなげない。
6. 代表の工数は、**最初の2週間で約2h（1h45m＋予備）、その後は週約1.5h**（相談が増えたら週2.5hまで）。

## 1. 顧客と「期待超え」の設計

| 顧客 | 期待していること | 想像していないが喜ぶこと（岳燈が足すもの） |
|---|---|---|
| Threadsの読者 | 共感できる話、ヒント | 「本業×挑戦」の**時間と数字をそのまま見せる記録**。うまくいかなかった月も出す |
| 相談に来た人 | 志スクールの説明 | 入学するかどうかに関係なく、相談から24時間以内に**「志の言語化メモ」**（相談内容の要約・その人の強み・次の一歩3つ）を受け取れる。AI社員が下書きし、代表が確認して送る |
| 志スクール | 入学者 | 理念に合うことを確かめた人だけが来るので、**定着しやすい入学者**。紹介時に相談メモ（本人の同意を得たもの）を共有でき、入学後のフォローが楽になる |
| 代表 | 月1万×在籍人数の収入 | 投稿を考える必要がない（週1回の一括承認だけ）。相談は1件20分で終わる |

## 2. 代表に確認したいこと（3つだけ）

志スクールの理念の詳細が分からないため、次の3点を確認する。**2026/10/5（決裁期限）までに一言ずつで構わない。**

| # | 確認事項 | なぜ必要か |
|---|---|---|
| ① | **志スクールの理念を一文で。どんな人に入ってほしいか、受講料・期間はどのくらいか** | ペルソナ、発信テーマ、解約率の仮定（今は月5%と置いている）が決まる |
| ② | **紹介制度のルール**：報酬の条件（在籍中は毎月か・上限期間・支払い時期）／SNSで募集してよいか、スクール名を出してよいか／報酬の表示方法に指定があるか／**入学した人も紹介報酬を得られる仕組みか** | 収益の計算と、コンプライアンスの判断（§7）に必要。最後の点は特定商取引法の判断材料になる。確認用の質問文は秘書が用意する |
| ③ | **代表が志スクールに入った理由と、得られたもの（実名・顔出しをしてよいかも）** | 発信の核になる話。作り話は書けないので、代表の実体験が要る |

## 3. 誰に：ペルソナ（仮説。確認①のあとに更新する）

**主ペルソナ【推測】**：「本業に不満があるわけではないが、このままでいいのかと感じている 20〜40代の会社員・専門職（医療職を含む）」

| 項目 | 内容（仮説） |
|---|---|
| 状況 | 平日はフルタイムで働き、夜と週末に「何かを始めたい」と思っているが、一人では続かない |
| 悩み | やりたいことが言葉にならない／周りに挑戦している仲間がいない／情報商材のようなものには警戒している |
| Threadsでの行動 | 夜や通勤中に流し読みし、共感した投稿にリプライする。売り込みはすぐに見抜く |
| 決め手 | 「この人が本当にやっている」という実感と、無理に勧めてこない安心感 |
| **紹介しない人** | すぐに稼ぐ方法だけを求める人／理念に関心がない人／経済的に無理がある人 → 相性確認で「今は勧めない」と伝える |

代表との共通点（本業あり・通勤あり・夜2時間）がそのまま信頼の材料になる。

## 4. 何を発信するか

### 4-1. アカウントの軸
**「平日フルタイムの薬剤師が、夜2時間で志を形にしていく記録」**
- 「薬剤師」は属性として書くだけにし、健康・薬の情報は発信しない（§7-3）。
- 勤務先の名前・地域は出さない。

### 4-2. 投稿の柱と比率

| 柱 | 比率 | 中身 | 型 |
|---|---|---|---|
| A. 挑戦の記録 | 4割 | 今週使った時間、やったこと、うまくいかなかったこと | 数字＋一言の振り返り |
| B. 志を言葉にする問い | 3割 | 「10年後も続けたいことは？」のように、読者が答えたくなる問い | 問いかけ（Threadsは会話が伸びやすい【推測】） |
| C. 学びの共有 | 2割 | 志スクール・本・コミュニティで学んだことを一つだけ持ち帰る形で | 要約＋自分ならどう使うか |
| D. 紹介・案内 | 1割以下 | 志スクールの説明会の案内、仲間の紹介（本人の許可を得たもの） | **必ず報酬を明示（§7-1）**。ルールを確認するまでは投稿しない |

### 4-3. 頻度
- **1日1本（平日は予約投稿）＋週2回の問いかけ投稿**。まとめると週9本程度。
- 下書きはすべてAI社員が作る。代表は**月曜午前に1週間分を一括で承認**する（約20分）。
- 予約投稿は Threads のアプリ内機能を使う想定（機能の有無はリサーチ担当が確認する【未確認】）。使えない場合は、代表が通勤中にコピーして投稿する（1本1分）。

## 5. どう関係を深めるか（導線）

```
① 投稿を読む
   ↓（プロフィール・固定投稿）
② 固定投稿「こんな人と話したい／こんな人には勧めない」＋報酬の明示
   ↓（DMで「話を聞きたい」と送ってもらう。こちらから売り込みのDMは送らない）
③ DMで事前質問3つ（今の状況／やりたいこと／スクールに興味があるか）
   ↓
④ 20分のオンライン相性確認（代表）：冒頭で報酬関係を口頭で伝える
   ↓ 24時間以内に「志の言語化メモ」を送る（AI下書き → 代表確認）
⑤ 相性が合えば、志スクール公式の説明会・体験を案内（詳しい説明は公式に任せる）
   ↓
⑥ 入学（本人が決める。入学後も月1回の近況リプライで関係を続ける）
```

**やらないこと**
- こちらから一斉DM・自動DMを送らない（プラットフォームの規約違反と、信頼を失うリスクがあるため）
- 「今だけ」「必ず変われる」「稼げる」などの表現を使わない
- 入学を迷っている人を追いかけない（2回案内して返事がなければ終わりにする）

**イベント（任意・2027年1月以降）**：月1回、30分のオンライン「志を言葉にする会」（最大6人）を開く。相性確認をまとめて行えるため、相談1件あたりの時間が下がる。関門1（12月末）で相談数が月5件を超えていたら検討する。

## 7. コンプライアンス（必須）

### 7-1. ステマ規制（景品表示法）への対応
**【事実】** 2023年10月1日から、景品表示法第5条第3号に基づく告示（「一般消費者が事業者の表示であることを判別することが困難である表示」）により、いわゆるステルスマーケティングが不当表示として規制されている。規制の対象は**広告主（この場合は志スクール）**で、報酬を受けた第三者の発信でも、広告主が内容に関与していれば「広告主の表示」とみなされる。消費者庁の運用基準では、「広告」「宣伝」「PR」などの文言で、**一般消費者が分かるように明瞭に**示すことが求められている。

**代表個人は直接の処分の対象ではない【事実：規制対象は事業者】が、次の理由で必ず明示する**：①志スクールに迷惑をかけない ②紹介者としての信頼を守る ③後から「実は報酬をもらっていた」と分かるのが一番信頼を失う。

| 場所 | 表示のしかた（案） |
|---|---|
| プロフィール | 「志スクール在籍。紹介した方が入学すると、私に紹介報酬が支払われます。」 |
| 志スクールに触れる投稿 | 冒頭に **【PR】** ＋本文の最後に「※紹介報酬があります」。ハッシュタグの束の中に埋もれさせない |
| DM・相性確認の冒頭 | 「最初にお伝えします。紹介した方が入学すると、私に報酬が入ります。入学しなくてもまったく問題ありません」 |
| 志の言語化メモ | 末尾に同じ一文を入れる |

- 志スクール側に表示方法の指定があれば、それに従う（確認②）。
- 学びの共有（柱C）でスクール名を出すだけの投稿にも【PR】をつける。「報酬と関係する可能性がある投稿はすべて表示する」を原則にし、迷ったら表示する。
- Threads（Meta）のブランドコンテンツ規約と、有償パートナーシップの表示機能があるかをリサーチ担当が確認する【未確認】。

### 7-2. 志スクール側の紹介ルールの確認（**始める前の必須事項**）
- SNSで募集してよいか、スクール名・ロゴを使ってよいか、禁止されている表現はあるか
- **入学者も紹介報酬を得られる仕組みか**：そうであり、入学に費用がかかる場合、**特定商取引法の「連鎖販売取引」に当たる可能性がある【推測：条文上の要件に照らした一般論】**。当たる場合は、勧誘時の氏名などの明示、書面の交付、誇大な表現の禁止など、多くの義務がかかる。**確認②の答えによっては、弁護士など専門家への確認を挟むか、施策そのものを見送る。**
- 相談者の情報を志スクールに渡すときは、必ず本人の同意を得る（個人情報保護）。

### 7-3. 薬剤師としての本業・医療情報との切り分け
- 健康・薬・病気の情報は発信しない。質問が来ても個別には答えず、「かかりつけの医師・薬剤師にご相談ください」と返す（定型文は編集担当が用意する）。
- 勤務先の名前・地域・患者さんに関する話は一切出さない。
- 循環器の受託アカウント（クライアントのもの）では志スクールに触れない。相互のフォローや誘導もしない。
- 勤務先の副業規定に、紹介報酬を受け取ることが含まれていないかを確認する（ロードマップ v2 §9）。

### 7-4. 表現のチェック
- 編集担当が投稿ごとに「報酬の表示／誇大表現（稼げる・必ず・誰でも）／医療情報が混ざっていないか」の3点をチェックしてから承認に回す。

## 9. 「アウトプットの場」案との関係

`strategy/2026-09-23_アウトプットの場.md`（個人X＋note、医療系SNS運用のノウハウが軸）とは**見込み客が違う**ため、アカウントは分ける。
- 個人X・note：医療系アカウントの運用者・医療者 → 運用代行・メンター・講座の顧客
- Threads：本業を持ちながら挑戦したい人 → 志スクールへの紹介
